# esp32c3-temp-server
Temperature monitoring server for esp32c3 with dht11.

# Hardware used in this project
- esp32c3
- dht11

# Install
- You can follow [this](https://esp32.implrust.com/dev-env.html) for esp32 with rust
- change SSID, PASSWORD, GATEWAY_IP, STATIC_IP on esp32c3-temp-server/src/bin/main.rs
- cargo run --release
- enjoy your devices
